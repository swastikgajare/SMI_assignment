Mall Customer Segmentation Using Machine Learning

This project focuses on segmenting customers based on demographic and spending behaviour using unsupervised machine learning techniques.

Project Overview

The analysis uses the Mall Customers dataset to identify meaningful customer groups based on age, annual income, and spending score.

Key Steps
Data exploration and quality assessment
Data preprocessing and feature scaling
Exploratory data analysis and correlation analysis
Optimal cluster selection using the Elbow Method and Silhouette Score
K-Means clustering
Hierarchical (Agglomerative) clustering
PCA-based dimensionality reduction for visualization
Cluster comparison and customer profiling
Technologies Used
Python
Pandas
NumPy
Scikit-learn
Matplotlib
Seaborn
SciPy
Objective

To identify distinct customer segments that can help businesses understand customer behaviour and support data-driven marketing strategies.
